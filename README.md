# JNPR Club

Local portfolio website for Mariana Ortega. This repository contains only the public-facing website; the private TD7 Brand Hub, client accounts and working data live separately.

## Preview

Run `python3 -m http.server 8766 --bind 127.0.0.1` from this directory, then open `http://127.0.0.1:8766/split.html`.

## Current source

- `split.html`: homepage and project views.
- `entry.js`: homepage entrance.
- `magazine.js`: Pocoyo catalogue.
- `sound.js`: optional sound effects.
- `img/`, `tex/`, `fonts/`, `audio/`: website assets.

## Agreed direction

Preserve the retro visual language, PP Monument Wide, orange and blue, chrome, vinyl sleeves and cassettes. Keep the homepage concise. Smart Branding is Mariana Ortega's own proposal, in development, combining a brand system, Brand Hub, AI-assisted creation and ongoing collaboration with the lead designer through a subscription.

JNPR Lab will present Brand Hub, AI Studio and Websites through a retro chrome computer. Demonstrations must distinguish implemented features from planned functionality and must not expose private Hub data. Vertical videos retain their 9:16 framing.

GitHub hosting and deployment are not configured yet. Do not publish automatically.
